# 🔗 ShortyURL

> **Short links. Zero hassle.**

ShortyURL is a simple and fast URL shortener built with **Next.js**.
Create clean, shareable short links without creating an account or going through unnecessary setup.

---

## ✨ Features

* ⚡ **Fast & Simple** — Shorten URLs in seconds.
* 🔓 **No Login Required** — No signup or account needed.
* 🎯 **Custom Short URLs** — Choose your own short URL text.
* 📊 **Link Analytics** — Track useful insights such as clicks and other link activity.
* 📱 **Responsive Design** — Works smoothly across desktop, tablet, and mobile.
* 🔗 **Easy to Share** — Get a clean, compact URL ready to share.
* 🛡️ **Secure & Reliable** — Built with modern web technologies.

## 🚀 Getting Started

Follow these steps to run ShortyURL locally.

### 1. Clone the repository

```bash
git clone https://github.com/siddharthgaikwad-git/ShortyURL.git
```

### 2. Navigate to the project

```bash
cd ShortyURL
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create environment variables

Create a `.env.local` file in the root directory:

```env
MONGODB_URI=your_mongodb_connection_string
NEXT_PUBLIC_HOST=http://localhost:3000
```

Replace the values with your own configuration.

### 5. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🔄 How It Works

The process is intentionally simple:

```text
Enter your URL
      ↓
Choose a short URL
      ↓
Generate
      ↓
ShortyURL creates the link
      ↓
Share your short URL
```

For example:

```text
https://example.com/my-very-long-page
                    ↓
https://shortyurl.com/my-link
```

## 🎯 Why ShortyURL?

Many URL shorteners add unnecessary steps before you can create a link.

ShortyURL focuses on the basics:

> **Paste → Shorten → Share**

No account required.
No complicated setup.
Just a short link.
